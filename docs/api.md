# API reference

API of the modules gdsfactoryx adds to gdsfactory. For the gdsfactory API
(`Component`, cells, routing, PDKs, ...), see the
[gdsfactory API reference](https://gdsfactory.github.io/gdsfactory/api/); the
differences are listed in
[Differentiable layouts](differentiable.md#api-differences-from-upstream-gdsfactory).
